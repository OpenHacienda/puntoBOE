# Especificaciones técnicas

## Modelo 720 — Diseño de registro

**Fichero:** `modelo_720_disenyo_registro.pdf`  
**Fuente:** Agencia Estatal de Administración Tributaria (AEAT)  
**URL:** https://sede.agenciatributaria.gob.es/static_files/Sede/Disenyo_registro/DR_Resto_Mod/archivos/modelo_720.pdf  
**Normativa:** Orden HAP/72/2013 — https://www.boe.es/buscar/act.php?id=BOE-A-2013-842

Documento oficial que describe el diseño de registro del fichero BOE para la
declaración informativa sobre bienes y derechos situados en el extranjero
(Modelo 720): estructura de los registros tipo 1 y tipo 2, posiciones de cada
campo, longitudes, valores admitidos y criterios de validación.
