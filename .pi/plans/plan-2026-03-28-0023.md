# Plan: Editor para generar ficheros 720 BOE

## Decisiones de diseño
- **Nuevo crate `generator720`** — genera registros de 500 chars en ISO-8859-1, calcula totales automáticamente
- **Ruta `/editor`** — requiere añadir `leptos_router 0.7` al crate app
- **Importar .720 existente** — reutiliza `parser::field()` (validator720) para poblar el formulario
- **Validación en vivo** — llama a `validate()` del crate validator720 sobre los bytes generados antes de descargar

---

## Archivos a crear / modificar

### 1. `crates/generator/Cargo.toml` *(nuevo)*
- Paquete `generator720`, deps: `encoding_rs`, `validator720 { path = "../validator" }`

### 2. `crates/generator/src/lib.rs` *(nuevo)*
- `pub struct Tipo1Fields` — NIF, nombre, ejercicio, tipo_soporte='T', dec_complementaria, dec_sustitutiva, num_dec_anterior
- `pub struct Tipo2Fields` — todos los campos editables de un registro T2 (nif_declarado, nombre, clave_bien, subclave, pais, id_valores, fecha_inc, origen, fecha_ext, valoracion1, valoracion2, pct_participacion, clave_inmueble, etc.)
- `pub fn generate_file(t1: &Tipo1Fields, records: &[Tipo2Fields]) -> Vec<u8>` — construye 500-char records, computa totales T2 e inyecta en T1, encoda ISO-8859-1 con `encoding_rs::WINDOWS_1252`
- Helpers privados: `pad_right(s, n)`, `pad_left_zeros(n, len)`, `encode_amount(val: f64) -> (char, String)`
